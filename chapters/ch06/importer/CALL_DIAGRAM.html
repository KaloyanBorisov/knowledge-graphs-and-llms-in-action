A full run reads diary pages from JSON, has an LLM extract entities from each page, cleans and merges those entities, builds a typed knowledge graph, then scores the people in it. The code is split by aspect, and FullKG is assembled from mixins that share one Neo4j driver.

entry: ingest_and_process.pyrun: make import

Four stages of a run

The entry script calls stage 1 and stage 4 itself. Stages 2 and 3 are both driven by one call, build_kg(prompt_path).

Stage 1 · load

Load pages

  • DiariesImporter(argv)
  • create_indices()
  • ingest_diaries(json)
  • count_diaries(), get_diaries()
  • batch_store()

(:File)-[:CONTAINS_PAGE]->(:Page)

Stage 2 · extract

LLM extraction

  • read_prompt()
  • process_diaries_gpt()
  • openai_query()
  • parse_gpt_output()
  • store_to_neo4j()

Entity nodes and RELATED_TO_ENTITY; page marked :GPTProcessed

Stage 3 · build

Normalise, resolve, create

  • normalize_entities()
  • resolve_entities()
  • create_kg()

Person, Organization, Occupation, Title with WORKS_FOR, TALKED_WITH and others

Stage 4 · analyse

Graph analytics

  • run_gds()
  • project, WCC, largest component
  • PageRank, eigenvector, betweenness, Louvain
  • influencer projection

Person.wcc, pagerank, eigenvector, betweenness, community, pr_influencers
